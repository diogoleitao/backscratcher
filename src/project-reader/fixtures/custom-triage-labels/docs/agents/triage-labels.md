# Triage Labels

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `triage`             | Maintainer needs to evaluate this issue  |
| `needs-info`               | `waiting-on-reporter` | Waiting on reporter for more information |
| `ready-for-agent`          | `afk`                | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `hitl`               | Requires human implementation            |
| `wontfix`                  | `wontfix`            | Will not be actioned                     |
